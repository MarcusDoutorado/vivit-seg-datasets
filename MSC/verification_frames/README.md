# MSC verification frames

3 low-resolution (480px-wide) frames per movie, one subfolder per movie (`msc_<id>/`), from shots spread across each film (~15%, 50%, ~85% through its shot list), so someone with their own legitimately-sourced copy can extract the same frame and compare. See `docs/methodology.md` (repo root) for the naming convention and the reasoning behind keeping these low-res and few-per-movie.
